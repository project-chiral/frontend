# Project Chiral (开罗尔计划)

Project Chiral 是一个专为创作者设计的**叙事建模工具**。通过将复杂的叙事逻辑抽象为可视化的模型，辅助创作者进行世界观构建、时序规划和剧情设计。

## 🌟 核心功能

### 1. 多维工作台 (Workbench)
工作台支持高度自由的布局，创作者可以通过拖拽方式在工作台的四角、侧边或中心放置多个功能组件。
- **组件联动**：各组件间实时同步。例如，在时序图中选定事件，编辑器会即时展示其详细内容。
- **动态交互**：组件未挂载时，相关内容将以模态框形式展现，确保工作流不中断。

### 2. 专业时序图 (Chronogram)
叙事建模的核心组件，区别于传统甘特图，专为描述复杂叙事关系而设计：
- **全尺度观察**：支持从“秒”到“世纪”的 8 级时间单位切换。
- **无限漫游**：支持无限水平滚动，支持跨越数万年的宏大历史跨度。
- **层级化事件**：引入“子事件”概念，支持将事件展开为更细粒度的低层级单位列表。
- **智能过滤**：仅展示与当前视图时间跨度相关的事件，保持视图简洁。

### 3. 叙事线与叙事树 (Narrative Logic)
实现“故事（Story）”与“话语（Discourse）”的分离：
- **独立链表**：叙事线是由“叙事节点”构成的独立逻辑链，可模拟倒叙、插叙等非线性叙事手法。
- **逻辑复用**：支持将因果关系图中的路径一键转化为叙事线，快速构建剧纲。
- **元信息扩展**：每个节点可独立记录叙述者、外部文档链接等关键信息。

### 4. 事件编辑器与角色建模
- **深度描述**：集成待办列表、详细元信息（时间、简介）及关联系统。
- **自动关联**：自动记录参与事件的人物、组织、地理位置及因果伏笔。
- **角色关系网**：角色组件自动汇总提及该角色的所有事件，动态生成角色的生命轨迹。

## 🛠 技术栈

本项目基于现代前端技术栈构建，追求极致的开发体验与运行性能：

- **Runtime**: [Bun](https://bun.sh/)
- **Framework**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [Radix UI](https://www.radix-ui.com/) & [Lucide Icons](https://lucide.dev/)
- **State Management**: [Zustand](https://zustand-demo.pmnd.rs/)
- **Data Fetching**: [React Query](https://tanstack.com/query)
- **Routing**: React Router 7 (Hash Router)

## 📖 核心规则说明

### 时序展示规则
系统根据事件时长自动判定其时间层级（如 2 年归属于“年”层级）。展示方式遵循以下逻辑：
- **同级展示**：若有同级子事件则展示子项，否则展示自身。
- **高频聚合**：在更高级的时间单位下，短事件将以“若干事件”的虚拟父事件形式进行聚合展示。

### 关系建模
- **因果关系**：支持定义强烈因果、影响、伏笔等多种类别。
- **关系图**：用于表达事件之间真实的逻辑关联，独立于最终的叙事逻辑。
